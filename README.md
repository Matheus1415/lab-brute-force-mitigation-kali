Nunca execute testes de validação de credenciais em sistemas sem autorização prévia e formal.

---

## 📌 Sobre o Projeto

Este repositório documenta a análise técnica do módulo **Brute Force** da aplicação **DVWA (*Damn Vulnerable Web Application*)** através dos seus diferentes níveis de maturidade de segurança.

O objetivo principal é compreender como falhas na lógica de autenticação permitem a enumeração e descoberta de credenciais fracas, comparar o comportamento de ferramentas baseadas em linha de comando (**Hydra**) e proxies de interceptação HTTP (**Burp Suite**), e implementar estratégias sólidas de defesa em aplicações web modernas.
